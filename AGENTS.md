# Правила публичного Empire VPN

- Начинай с CURRENT.md и нужной задачи PLAN.md; не загружай всю историю автоматически.
- Репозиторий публичный. Не добавляй реальные credentials, private keys, токены, пользовательские профили, инфраструктурную инвентаризацию, личные пути и журналы эксплуатации.
- Код — installer/. Внутренние документы находятся в отдельном приватном репозитории empire451f-private; обычная локальная разработка не зависит от него.
- Никакие deploy, SSH/network/firewall/MTU, restart/reboot, удаление и серверные отказные тесты не входят в обычную правку кода. Для них нужны явные target/scope и доступ к приватным эксплуатационным правилам. Исторические разрешения не переиспользовать.
- Сохраняй существующие профили, точные credentials/case/status/master protection. Не печатай секретные конфиги или wg dump/showconf.
- Fail-closed для проксируемого трафика, DNS и IPv6 обязателен. Caddy/sing-box изолированы, непривилегированны, без CAP_NET_ADMIN и доступа к сети хоста. Для UoT upstream используется HTTP CONNECT, не SOCKS.
- Изменения группируй; проверяй необходимые целевые тесты. Реализованное, проверенное и отложенное различай; серверную приёмку не выводи из локальных тестов.
- Ищи через rg по известным путям, исключай сборки/зависимости. Не откатывай чужие изменения. До изменения правил сохраняй версию, before/SHA и откат; локальные неопубликованные snapshots не коммить в public без проверки.
- Не продолжай автоматически старые production/backlog задачи из опубликованной истории. История не является текущим заданием.
