# Ветки

Main — последний документально принятый релиз rc10; work — текущая разработка rc11. Серверное состояние не проверяется автоматически при push. Теги уже опубликованных выпусков неизменны.

Новые публичные коммиты строятся от опубликованных предков. Не переносить сюда приватные archive/* refs или полную историю внутреннего проекта. Старые опубликованные release/feature ветки сохраняются как исторические; новые задачи из них не активировать автоматически.

Обычный цикл: git status, git fetch origin, git switch work, git pull --ff-only, затем адресные изменения, тесты, commit и push. Исходники предпочтительно менять локально; API-правки через отдельную ветку/PR и последующий fetch.
