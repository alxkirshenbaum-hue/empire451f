# Клиентские учётные данные, версия1

Отдельный от полного backup контракт для будущей панели. Панель не реализуется. UTF-8 JSON вне репозитория:

```json
{
  "format": "empire-vpn-clients",
  "schema_version": 1,
  "clients": [
    {"username": "owner", "password": "REPLACE-WITH-YOUR-EXISTING-PASSWORD"}
  ]
}
```

Это пример, не готовые учётные данные. Список от1до100 уникальных usernames. Логин:1–64 символа `A-Z a-z 0-9 _ . @ -`; пароль:1–256 печатных ASCII-символов без управляющих символов и последовательности `{$` (подстановка окружения Caddy). Неизвестная версия или поля клиента отклоняются. Домен, адреса VDS, SSH/WG/TLS-ключи и профили SFA сюда не входят: перенос учётных данных не привязан к провайдеру.

Q13 импортирует значения без замены. Без импорта установщик сохраняет созданный экспорт в `~/.config/empire-vpn/ID/clients.json`. При повторе используется прежний файл. Отличающийся новый импорт не применяется как неявная ротация. Для существующей legacy-пары логин/пароль можно ввести скрыто при создании; архив старого сервера не нужен.

Файл содержит секреты в открытом виде. Доступ ограничивается владельцем, экспорт не входит в Git, дистрибутив и вывод мастера. Копирование файла, чтение backup и выдача профилей клиентам выполняются пользователем; установщик не меняет старые клиентские профили.
