# Empire VPN

Публичные исходники установщика и панели. [Код и пользовательская инструкция](installer/README.md), [сборка](BUILD.md), [ветки](BRANCHES.md).

Код находится в installer/; preview сайта — site-preview/ и site-v3-preview/. Внутренние эксплуатационные планы, инвентаризация и архив контекста ведутся отдельно, в приватном empire451f-private. Они не нужны для локальной проверки кода.

Существующие release tags и адреса скачивания в empire451f сохранены. Локальное имя папки empirevpn не меняет URL опубликованных выпусков. Production автоматически не обновляется от push.
