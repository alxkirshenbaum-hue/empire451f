# Проверки v0.1.0 — 10 ноября 2026

Локальная среда: Windows; Python3.12, Windows PowerShell5.1 и PowerShell7 доступны. Настоящего macOS и Linux/systemd/netns окружения нет. Новые и действующие VDS не изменялись; DNS не переключался.

Итог локального набора: **26 PASS, 1 SKIP** (реальный macOS). Покрыты обе роли с тестовыми адресами, HTTP/UoT и правила fail-closed в сформированных файлах, зависимости сокетов, импорт/экранирование credentials, валидация ввода, защита адресов, повтор без изменений, отказ при неизвестных/изменённых файлах, preview без subprocess/записи/генерации секретов, сохранение credentials, классификация SSH, исправление ответа мастера, контроль checksum, отсутствие секретов в ошибках, сохранение WG-ключа и защита от устаревшего отката.

Искусственный сбой активации проверен с настоящими временными файлами и подменёнными Linux-командами: прежний файл восстановлен, созданный удалён, pending очищен, глобальный flush не вызывается. Legacy-выход: генератор сохраняет старые WG-правила и путь прежнего ключа, добавляет маркированные разрешения нового туннеля. Это локальные проверки адаптера, не применение на сервере.

В **настоящих Windows PowerShell5.1 и PowerShell7** выполнен входной скрипт с offline-preview. В обоих выполнен загрузчик: вместо сети подавался тестовый ZIP исходников с безвредной заглушкой клиента. Проверены SHA256, распаковка, запуск общего исполнителя, повтор и отказ после изменения скачанного файла. Тестовый ZIP не является архивом сервера и не участвует в развёртывании. В рабочем ZIP только код/шаблоны установщика; компоненты загружаются с официальных источников. Сам факт разбора Python/PowerShell не считается развёртыванием.

Не испытаны: полный bootstrap на чистом Windows без Python/OpenSSH; реальный macOS zsh/bash и установка pkg; установка на чистую Ubuntu24.04; nft/systemd validation в Linux; сборка Caddy на новой VDS; legacy-adapter на работающих серверах; фактические TCP/UoT/отказ WG/reboot через новый установщик; ACME-получение и продление. Эти проверки встроены в код или перечислены в MIGRATION_TEST.md, но не обозначены PASS заранее.
