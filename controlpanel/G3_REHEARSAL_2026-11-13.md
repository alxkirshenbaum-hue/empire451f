## Права и реальные режимы

- В копии Caddy — UID/GID 65534, relay — 65533, API — 65532; фактический CapEff=0 у всех трёх, сетевой namespace один и изолирован. Эти числовые идентичности не являются ещё утверждёнными production-аккаунтами.
- Admin socket: владелец 65534, **0200**, каталог того же владельца **0700**. Режим наблюдён, а не предположен равным 0600. Прямой доступ UID API и relay отклонён. Через клиентский proxy нет данных admin на TCP/2019; `/config/` по HTTPS отдаёт обычный сайт. SOCKS ACK сам по себе не считается доказательством доступа.
- В копии проверены режимы echo TCP/UoT. Отдельно на существующих двух пользователях nh1 прошли настоящие `exit_https` с ожидаемым выходом, DNS через UoT, доверенный TLS, сайт и отказ неверному паролю. Это read-only проверка прежних пользователей, не создание нового пользователя на nh1. Исходник probe — `a9d86dd`, неизменён в `65ff2e2`.
