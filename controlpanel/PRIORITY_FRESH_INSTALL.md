## Инструкция Lead/Subagents

Сначала безопасно остановить W8-работу и сообщить смену приоритета своим агентам. Затем посмотреть build_release.py, bootstrap, controller.py и готовые команды установки панели из G3/G7. Подготовить короткий конкретный план интеграции и выполнять его в текущем разрешённом local/staging scope. Новые helper/атомарные процессы/журналы только при обнаруженной необходимой зависимости, с кратким объяснением; не расширять существующие safety-матрицы по инерции.

Передать независимые упаковку/инструкции агенту только если это ускоряет работу. Lead владеет интеграцией и итоговым E2E. Итог для владельца — команда установки и работающий сценарий, а не статус улучшения harness. Production в рамках корректировки документации не изменяется.
