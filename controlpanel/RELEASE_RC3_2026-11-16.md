## Defect and correction

VPN commit completed, then registry initialization refused the shared root lock
with mode0644. Controller's open(a) under umask022 created it; touch(mode0600)
did not normalize an existing file. Owner password/bootstrap had not run, panel
DB/key/units were absent. Read-only diagnosis confirmed mode/root ownership and
published binary/template hashes. This is an installer defect.

Commit7c7b679 reuses one safe fd-based opener at existing Python lock sites:
O_NOFOLLOW/CLOEXEC/NONBLOCK, fstat root/regular/single-link and lstat same-inode
checks, then fchmod0600. No unlink/replacement, existing flock semantics remain;
fd is closed before the Go command takes its own lock. Go checks are unchanged.
Panel command failures now name a fixed stage and exit code without raw argv,
stdout, stderr or credentials. Generic shutdown no longer claims active rollback.
Known-host help improvements are included. Q02/Q16/IP improvements stay BL-010.
