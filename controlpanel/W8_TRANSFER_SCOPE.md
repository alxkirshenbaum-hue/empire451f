## Ограниченный повтор rollback

Запущен локальный controller8708435 с --resume-source, исходным851541 и новым destination851591; исходный backup повторно не создавался. Новый restored runtime завершился, source rollback теперь остановился на FileExistsError('/run/vpn-control/restore-api'), pilot/backup_restore_rehearsal.py:68. Исправленная проверка scratch пройдена, следующая проблема относится к повторному созданию тестового API-каталога. Общего rollback PASS пока нет. Следующее исправление должно проверять существующий private directory, владельца и отсутствие живого listener перед повторным использованием. Повторять только rollback-проверку source; полный export/restore уже имеет подтверждение.

## Минимальный пакет после согласования

1. Исправить повтор тестового API-каталога и завершить только source rollback с8708435; новых helper/служб для этого не нужно.
2. Сопоставить пользовательский вход импорта с существующими offline-verify/prepare/runtime механизмами. Зафиксировать одну документированную команду импорта на чистой установке, её предусловия (endpoint/TLS/маршрут) и отказ при непустом целевом реестре или несовместимости. Если команды ещё нет, согласованная реализация ограничивается этой связкой.
3. Один прогон Export → Import на чистой установке через эту команду. Сравнить логины, секреты и статусы внутри закрытого теста, проверить active PASS/disabled FAIL, профиль без изменений и контрольное создание/выдачу после импорта. Использовать прежние криптографические и отрицательные тесты, если код не изменился.
4. Записать четыре результата по сокращённым критериям, команды для владельца и закрыть G8 после фактической проверки. Полный аудит/ресурсную матрицу отдельно отслеживать при выпуске.
