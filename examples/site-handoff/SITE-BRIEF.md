# Инструкция агенту, который создаёт сайт

1. Прочитай тему и пожелания пользователя. Напиши законченный короткий текст, создай навигацию и адаптивную страницу. Добавляй страницы, только если они помогают теме.
2. Сохрани структуру архива: одна папка проекта, внутри site/index.html, рядом с ним другие HTML-страницы, внутри site/assets/ — стили, иллюстрации и видео. Используй относительные ссылки. Сайт должен работать непосредственно при открытии HTML и на обычном статическом сервере.
3. Используй простые имена файлов на латинице. Поддерживаются HTML, CSS, JS/MJS, SVG, PNG, JPEG, WebP, GIF, AVIF, ICO, WOFF/WOFF2, TTF, MP4, WebM, OGG, MP3, TXT, XML и webmanifest. Служебные файлы и README держи вне site/. Исключи симлинки, скрытые файлы, архивы, клиентские профили, ключи и конфигурации сервера. Оставь сведения об источниках медиа рядом с этой инструкцией.
4. Перед выдачей проверь ссылки с главной, загрузку ресурсов и вид на телефоне. Сохрани ZIP до 200 МиБ, распакованный сайт до 400 МиБ, максимум 4096 записей архива. Верни ZIP целиком и укажи, как открыть главную локально.
